Smart Playlists · Navidrome

Your taste.
Your rules.

Keep finding the music you want without rebuilding the same playlist by hand.

A playlist that keeps finding the right music.

Set the rules once and let Navidrome return the tracks that match. As you add music, listen, rate, and favorite, the results can change with your library.

Start from a built-in template or make your own. Combine conditions with groups, choose how to sort the results, and set a limit for the session you have in mind.

Native Smart Playlist creation and editing require Navidrome’s native API and suitable account permissions. Ordinary playlists remain available on other providers where supported.

Simple to start. Room to go deeper.

  • Combine filters and nested rule groups.
  • Target one or several music libraries.
  • Apply multiple sorts and result limits.
  • Import an existing NSP JSON definition.
  • Preview supported rules against the synced library.

The local preview depends on the fields Naviamp has indexed. If a field cannot be evaluated locally, the editor explains that limitation; your server remains responsible for the playlist’s results.
