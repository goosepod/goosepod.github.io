A few things to know

Does Naviamp include a music subscription?

Naviamp is a player for a collection you already have access to. Connect your own compatible music server or your Bandcamp collection; Naviamp does not supply a streaming catalog.

Can I try it without setting up a server?

Yes. Connect to https://demo.navidrome.org with username demo and password demo. This public demo has a sample collection and some features are restricted. About the Navidrome demo.

Does every service support every feature?

Capabilities depend on your provider, server configuration, and account permissions. Sonic discovery needs compatible similarity data, and native smart-playlist editing is a Navidrome enhancement. Read the full compatibility guide.

Can I listen offline?

Download music before you leave your connection. Naviamp provides download management, storage and cache settings, and an offline dashboard. Downloads depend on the permissions your server provides.

How do I install and update Naviamp?

Microsoft Store handles updates on Windows, and Mac App Store handles updates on macOS. The iPhone and iPad beta updates through TestFlight. For packages downloaded from GitHub, use the latest release and read its installation and upgrade notes. macOS and Windows standalone packages are unsigned and may show an operating-system warning. Current release and installation notes.

Where can I get help or suggest something?

Join the Naviamp Discord for questions and discussion, or report a problem on GitHub. Community translations are managed through Weblate.

Open, private, and yours

Your library stays with the service or server you choose. Naviamp contains no ads or third-party tracking SDKs, and credentials use operating-system secure storage where supported.

Provider capabilities differ, so Naviamp hides or gracefully falls back from server-specific features instead of leaving broken controls behind.

Naviamp is available for macOS, Windows, Linux, and Android. The iPhone and iPad beta is available through TestFlight; an unsigned arm64 IPA remains available for users who provide their own signing.

Naviamp is translated by its community using Weblate.
