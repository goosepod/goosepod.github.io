What it does

Your library, without compromise.

Browse, play, discover, and manage the music you already own—with a focused player instead of a generic server interface.

PLAYBACK

Made for listening

Gapless playback, ReplayGain, crossfade, waveform seeking, sample-rate controls, lyrics, queues, and rich now-playing details.

DISCOVERY

Find a new path

Sonic Mix, Sonic Path, track radio, related tracks, and autoplay turn server-side similarity into useful listening sessions.

LIBRARY

Everything close at hand

Albums, artists, tracks, genres, favorites, playlists, recently played music, random picks, and internet radio.

PLAYLISTS

Static or smart

Create and edit playlists, build reusable smart rules, and save generated sonic queues back to your server.

OFFLINE

Ready when the server isn't

Keep music and metadata available locally, with download workflows designed for phones and computers.

PERSONAL

Make it yours

Aurora gradients, album-art accents, configurable layouts, waveforms, compact modes, and desktop visualizers.

In the app

One library. Many views.

Naviamp shares its core model across platforms while keeping the host applications thin and native where the operating system demands it.

Built for self-hosted music.

Naviamp treats Navidrome as its first-class server target and works with compatible OpenSubsonic servers. Connect your own account, then use the library and playback workflows without handing your listening habits to an advertising platform.

  • Your music remains on the server you choose.
  • Naviamp does not include ads or third-party tracking SDKs.
  • Credentials use the operating system's secure storage where supported.
  • Features gracefully hide or fall back when a server capability is unavailable.
