Playback format support

Direct playback across every Naviamp platform.

Compatibility means Naviamp ships a decoder for that platform, but the format is not yet part of the fully tested cross-platform release contract. A dash means Naviamp does not currently promise direct playback there; a Navidrome server may still make the file playable by transcoding it.

Naviamp + Navidrome support

Core features and the server enhancements that unlock more.

Most app behavior is shared across every release platform. Server-backed features depend on the connected account's permissions and on the capabilities the server advertises; Naviamp removes controls that the active server cannot fulfill.
