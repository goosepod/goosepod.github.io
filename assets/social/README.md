# Header icons

- `discord.svg`: Discord mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/discord.svg), distributed under CC0-1.0.
- `github.svg`: `mark-github-24` from [GitHub Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg), distributed under the MIT license retained in `OCTICONS-LICENSE.txt`.

SVGs are served locally. Link labels and hover titles live in the page markup; the images are decorative because the links already have accessible names.
